# Deadline Diagnosis (마감 진단)

『마감의 신 — 마감이 우리 삶을 압도하기 전에』(윤상혁)의 30문항 자가점검을 온라인에서 수행하는 웹페이지다.

## 소개

- A~E 다섯 묶음을 한 화면에 하나씩, 문항마다 5점 척도로 응답한다.
- 결과 화면에서 주로 맞닥뜨리는 마감의 종류(생존, 협업, 기회, 성장)와 마감 행동 유형(즉시 착수형, 막판 집중형, 완벽 준비형, 회피·망각형)을 각각 상대 비중(%)으로 보여준다.
- 비중이 가장 높은 조합에 대한 처방을 제시하고, 16개 조합 처방표 전체를 함께 제공한다.

## 실행

정적 페이지 하나로 구성되어 있어 별도의 빌드나 서버가 필요 없다.

- 온라인: GitHub Pages 주소로 접속한다.
- 로컬: `index.html`을 브라우저로 연다.

## 구조

- `index.html` — 문항, 채점 로직, 처방 텍스트, 스타일을 모두 담은 단일 파일이다.
- 문항과 마감 종류의 매핑은 `index.html` 안의 `TYPE_MAP` 상수에서 수정할 수 있다.

## 저작권

문항과 처방 텍스트의 저작권은 저자에게 있다. 이 진단은 참고용 자가점검이며 심리검사가 아니다.
